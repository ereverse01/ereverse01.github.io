# 구글 시트 설정 — 답 모으기 + 질문 공개 + 제출 현황 + 선생님 필기 공유

이 Apps Script 하나가 하는 일:
- 학생이 "선생님께 제출"을 누르면 시트에 답이 한 줄씩 쌓인다. **지문마다 시트 탭이 따로** 생긴다 (첫 지문은 첫 번째 탭).
- 선생님이 "공개"를 누르면 학생 화면에 그 질문·해석이 나타난다 (지문마다 따로).
- 선생님 화면의 **📋 제출 현황**에서 시트에 쌓인 답을 바로 본다 (비밀번호가 맞을 때만).
- 선생님 화면의 필기가 학생 화면에도 보인다 (**📡 학생에게 보이기**). 필기는 `_marks` 탭에 저장된다 — 이 탭은 지우지 않는다.

## 처음 설정할 때

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만든다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 들어 있는 코드를 모두 지우고 아래 코드를 붙여 넣는다.
4. 첫 줄의 `"여기에-비밀번호"`를 선생님만 아는 비밀번호로 바꾸고 저장한다.

```javascript
var TEACHER_KEY = "여기에-비밀번호";

var FIRST_LESSON = "finding";   // 첫 지문: 예전처럼 첫 번째 시트 탭과 저장 이름을 쓴다

function props() { return PropertiesService.getScriptProperties(); }
function openKey(l) { return !l || l === FIRST_LESSON ? "open" : "open:" + l; }

// 지문별 답 시트 (첫 지문은 첫 번째 탭, 나머지는 지문 이름의 탭)
function sheetFor(l) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  if (!l || l === FIRST_LESSON) return ss.getSheets()[0];
  return ss.getSheetByName(l) || ss.insertSheet(l);
}

// 선생님 필기: _marks 탭에 지문마다 한 줄 (긴 글은 여러 칸에 나눠 담는다)
function marksSheet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  return ss.getSheetByName("_marks") || ss.insertSheet("_marks");
}
function findMarksRow(sh, l) {
  var last = sh.getLastRow();
  if (!last) return 0;
  var ids = sh.getRange(1, 1, last, 1).getValues();
  for (var i = 0; i < ids.length; i++) if (ids[i][0] === l) return i + 1;
  return 0;
}
function readMarks(l) {
  var sh = marksSheet(), row = findMarksRow(sh, l);
  if (!row) return [];
  var cells = sh.getRange(row, 2, 1, sh.getLastColumn()).getValues()[0];
  var text = cells.join("");
  return text ? JSON.parse(text) : [];
}
function writeMarks(l, text) {
  var sh = marksSheet(), row = findMarksRow(sh, l) || sh.getLastRow() + 1;
  var cells = [l];
  for (var i = 0; i < text.length; i += 40000) cells.push(text.slice(i, i + 40000));
  if (sh.getMaxColumns() < cells.length) sh.insertColumnsAfter(sh.getMaxColumns(), cells.length - sh.getMaxColumns());
  sh.getRange(row, 1, 1, sh.getMaxColumns()).clearContent();
  sh.getRange(row, 1, 1, cells.length).setNumberFormat("@").setValues([cells]);
  props().setProperty("marksV:" + l, String(Date.now()));
}

// 학생 화면이 몇 초마다 '지금 공개된 질문'과 '선생님 필기 버전'을 물어본다
function doGet(e) {
  var p = e.parameter || {}, l = p.lesson || FIRST_LESSON;
  if (p.marks) return json({ marks: readMarks(l) });
  var open = props().getProperty(openKey(l)) || "[]";
  var mv = props().getProperty("marksV:" + l) || "";
  return json({ open: JSON.parse(open), marksV: mv, v: 5 });   // v: 지금 작동 중인 코드 버전
}

function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  // 숫자·글자 형태가 달라도 같은 비밀번호로 본다
  var teacher = String(d.key).trim() === String(TEACHER_KEY).trim();
  var l = d.lesson || FIRST_LESSON;

  // 선생님: 질문·해석 공개·숨기기
  if (d.action === "open") {
    if (!teacher) return json({ ok: false });
    props().setProperty(openKey(l), JSON.stringify(d.open));
    return json({ ok: true, open: d.open });
  }

  // 선생님: 제출 현황 보기
  if (d.action === "list") {
    if (!teacher) return json({ ok: false });
    var s = sheetFor(l);
    var rows = s.getLastRow() ? s.getDataRange().getDisplayValues() : [];
    return json({ ok: true, rows: rows });
  }

  // 선생님: 필기 공유
  if (d.action === "marks") {
    if (!teacher) return json({ ok: false });
    writeMarks(l, JSON.stringify(d.marks || []));
    return json({ ok: true });
  }

  // 모르는 요청은 시트에 쓰지 않는다
  if (d.action) return json({ ok: false });

  // 학생: 답 제출
  var sheet = sheetFor(l);
  if (sheet.getLastRow() === 0) {
    // 질문 번호(Q1, Q2-1, Q2-2 …)는 학생 화면이 보내 준다
    sheet.appendRow(["제출 시각", "학번", "이름"].concat(d.labels || []));
  }
  sheet.appendRow([new Date(), d.sid, d.name].concat(d.answers));
  return json({ ok: true });
}

function json(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

5. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**, 실행 계정 **나**, 액세스 권한 **모든 사용자** → 배포.
6. 나온 **웹 앱 URL**을 `index.html`의 `const SHEET_URL = "";` 따옴표 안에 넣는다. (Claude에게 알려 주면 대신 넣어 준다.)

## 이미 배포한 스크립트를 고칠 때 (URL을 그대로 유지)

1. Apps Script에서 첫 줄(비밀번호)만 남기고 나머지를 위 코드의 둘째 줄부터 끝까지로 바꾼 뒤 저장한다.
2. **배포 → 배포 관리** → 연필(편집) 아이콘 → 버전에서 **새 버전** 선택 → **배포**.
   - "새 배포"를 누르면 URL이 바뀌니 주의한다. 바뀌었다면 새 URL을 index.html에 다시 넣어야 한다.
3. 처음 `_marks` 탭이나 지문 탭을 만들 때 권한을 다시 물을 수 있다. 본인 계정으로 승인한다.

## 수업에서 쓰는 법
- 선생님은 학생 링크 끝에 `?teacher`를 붙여 연다. 지문이 여러 개면 맨 위 탭으로 고른다.
- 질문 카드·해석 칸마다 **공개** 버튼. 누르면 약 5초 안에 학생 화면에 열린다. 다시 누르면 숨겨진다.
- **📡 학생에게 보이기**가 켜져 있으면 선생님이 그은 펜·형광펜·도장이 약 5~10초 뒤 학생 화면에 나타난다. 학생은 지울 수 없다. 끄면 학생 화면에서 사라진다.
- **🔦 강의 모드**: 화면을 어둡게 하고 한 문장씩 밝게 보여 준다 (선생님 화면에만).
- **📋 제출 현황**: 학생별 / 질문별, 최신 제출만, 20초마다 자동 새로고침. **🆕 새 반 시작**으로 다음 반을 시작한다.

## 알아 둘 점
- 학생 태블릿이 인터넷에 연결되어 있어야 질문이 열리고 선생님 필기가 보인다.
- 시트에는 키보드로 쓴 답만 전송된다. 펜 필기는 PDF로 받는다.
- 웹 앱 URL을 아는 사람은 시트에 줄을 추가할 수 있다.
