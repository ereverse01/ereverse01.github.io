# 구글 시트 설정 — 답 모으기 + 질문 공개

이 Apps Script 하나가 두 가지 일을 한다.
- 학생이 "선생님께 제출"을 누르면 시트에 답이 한 줄씩 쌓인다.
- 선생님이 "학생에게 공개"를 누르면 학생 화면에 그 질문이 나타난다.

## 처음 설정할 때

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만든다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 들어 있는 코드를 모두 지우고 아래 코드를 붙여 넣는다.
4. 첫 줄의 `"여기에-비밀번호"`를 선생님만 아는 비밀번호로 바꾸고 저장한다. 질문을 공개할 때 이 비밀번호를 한 번 입력한다.

```javascript
var TEACHER_KEY = "여기에-비밀번호";

// 학생 화면이 몇 초마다 '지금 공개된 질문'을 물어본다
function doGet(e) {
  var open = PropertiesService.getScriptProperties().getProperty("open") || "[]";
  return json({ open: JSON.parse(open), v: 3 });   // v: 지금 작동 중인 코드 버전 확인용
}

function doPost(e) {
  var d = JSON.parse(e.postData.contents);

  // 선생님: 질문 공개·숨기기 (숫자·글자 형태가 달라도 같은 비밀번호로 본다)
  if (d.action === "open") {
    if (String(d.key).trim() !== String(TEACHER_KEY).trim()) return json({ ok: false });
    PropertiesService.getScriptProperties().setProperty("open", JSON.stringify(d.open));
    return json({ ok: true, open: d.open });
  }

  // 학생: 답 제출
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  if (sheet.getLastRow() === 0) {
    // 질문 번호(Q1, Q2-1, Q2-2 …)는 학생 화면이 보내 준다
    sheet.appendRow(["제출 시각", "학번", "이름"].concat(d.labels || []));
  }
  sheet.appendRow([new Date(), d.sid, d.name].concat(d.answers));
  return json({ ok: true });
}

function json(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

5. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**, 실행 계정 **나**, 액세스 권한 **모든 사용자** → 배포.
6. 나온 **웹 앱 URL**을 `index.html`의 `const SHEET_URL = "";` 따옴표 안에 넣는다. (Claude에게 알려 주면 대신 넣어 준다.)

## 이미 배포한 스크립트를 고칠 때 (URL을 그대로 유지)

1. Apps Script에서 코드를 위 코드로 바꾸고 저장한다.
2. **배포 → 배포 관리** → 연필(편집) 아이콘 → 버전에서 **새 버전** 선택 → **배포**.
   - "새 배포"를 누르면 URL이 바뀌니 주의한다. 바뀌었다면 새 URL을 index.html에 다시 넣어야 한다.

## 수업에서 쓰는 법
- 선생님은 `선생님용.html`을 연다(또는 index.html 주소 끝에 `#teacher`를 붙인다). 질문 카드마다 **학생에게 공개** 버튼이 보인다.
- 버튼을 누르면 약 5초 안에 학생 화면의 그 질문이 열린다. 다시 누르면 숨겨진다.
- 다음 반 수업 전에는 도구 막대의 **질문 모두 숨기기**를 누른다.
- `선생님용.html`은 학생에게 나눠 주지 않는다. 학생이 선생님 화면을 열더라도 비밀번호가 없으면 공개 상태를 바꿀 수 없다.

## 알아 둘 점
- 학생 태블릿이 인터넷에 연결되어 있어야 질문이 열린다. 공개 상태를 계속 받아오지 못하면(연결 끊김, 스크립트 설정 전) 학생 화면에 모든 질문이 그냥 보인다.
- 시트에는 키보드로 쓴 답만 전송된다. 펜 필기는 PDF로 받는다.
- 웹 앱 URL을 아는 사람은 시트에 줄을 추가할 수 있으니, URL을 학생용 파일 밖에 공개하지 않는다.
