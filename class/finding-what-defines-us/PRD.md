# PRD — "Finding What Defines Us" 필기형 읽기 학습지

## ① 한 줄 정의
영어 지문을 보기 좋게 띄워 놓고, 학생이 갤럭시탭 펜으로 그 위에 필기하고 문단별 질문에 답한 뒤 PDF로 저장하는 한 장짜리 웹 학습지.

## ② 사용자
- **학생(주 사용자)**: 갤럭시탭 + S펜으로 수업을 듣는 학생. 자기 태블릿에서 index.html을 열어 필기하고 답을 적는다.
- **교사**: 지문을 설명하며 문단마다 질문을 던진다. 질문 문항은 교사가 Claude에게 알려 주면 index.html 코드에 직접 넣는다(편집 화면 없음).

## ③ 해결할 문제
- 종이 학습지 없이 태블릿만으로 지문에 밑줄·메모를 하기 어렵다.
- 설명 중간에 던지는 질문과 학생의 답이 지문과 따로 놀아, 나중에 복습할 때 연결이 안 된다.
- 필기와 답을 한 파일로 모아 제출·보관할 방법이 없다.

## ④ 핵심 기능 3개
1. **지문 보기**
   - 제목, 쪽수(101~104p), 문단을 넓은 줄 간격과 여백으로 제시한다.
   - Michelle Zauner 인용문은 인용 상자로 구분한다.
   - 지문은 총 7개 문단으로 나눈다.
2. **펜 필기 도구**
   - 지문 전체 위에 겹친 필기 레이어에 S펜으로 쓴다(펜으로는 필기, 손가락으로는 스크롤).
   - 도구: 펜 / 형광펜 / 지우개, 색 3~4가지, 굵기 2~3단계, 실행 취소, 전체 지우기.
   - 필기는 브라우저(localStorage)에 자동 저장되어 새로고침해도 남는다.
3. **문단별 질문 코너 + PDF 저장**
   - 문단마다 질문 카드 1개(총 7개). 카드에는 유형 표시(내용 이해 / 어휘 / 문법), 질문, 답 쓰는 칸이 있다.
   - 답은 키보드 입력 또는 펜으로 쓴다. 자동 저장된다.
   - 질문 문항은 코드 안의 목록 한 곳에 모아 두어, 교사가 알려 준 문항으로 쉽게 바꿔 넣는다. 문항을 받기 전에는 임시 문항을 넣어 둔다.
   - "PDF로 저장" 버튼 → 브라우저 인쇄 기능으로 지문 + 필기 + 질문과 답을 PDF로 저장한다. 맨 위에 학번·이름 칸을 둔다.
   - **교사에게 답 제출**
     - "선생님께 제출" 버튼 → 학번·이름과 Q1~Q7 답(키보드로 쓴 답)이 교사의 구글 시트에 한 줄로 쌓인다. 로그인 없음. 교사가 구글 Apps Script를 한 번 설정하고 그 주소를 코드에 넣어야 작동한다(`구글시트_설정.md` 참고).
     - PDF 파일을 교사가 정한 곳(클래스룸·메신저 등)에 제출한다. 펜으로 쓴 필기는 PDF로만 볼 수 있다.
     - "내 답 복사" 버튼 → 학번·이름과 Q1~Q7 답(키보드로 쓴 답)을 글자로 복사해 채팅방·패들렛 등에 붙여 넣는다.

## ⑤ 화면 구성
한 화면(세로 스크롤)으로 구성한다.

```
┌─────────────────────────────────────────┐
│ [펜][형광펜][지우개] ●●●● 굵기 ↶ 전체지움  [PDF로 저장] │ ← 상단 고정 도구 막대
├─────────────────────────────────────────┤
│ 학번 ____  이름 ____                       │
│ Finding What Defines Us                  │
│ 문단 1 ...                                │
│  ┌ Q1 [내용 이해] 질문 / 답 칸 ┐              │
│ ── 101p ──                               │
│ 문단 2 ...   ┌ Q2 ┐                       │
│ 문단 3 ...   ┌ Q3 ┐                       │
│ ── 102p ──                               │
│ 문단 4 ...   ┌ Q4 ┐                       │
│ ❝ 인용문(문단 5) ❞  ┌ Q5 ┐                  │
│ ── 103p ──  문단 6 ...  ┌ Q6 ┐            │
│ ── 104p ──  문단 7 ...  ┌ Q7 ┐            │
└─────────────────────────────────────────┘
```
- 갤럭시탭 가로·세로 모두에서 글자가 크게 보이도록 한다.
- 인쇄(PDF) 시에는 도구 막대를 숨기고 지문·필기·답만 나온다.

## ⑥ 이번에 만들지 않을 것
- 서버, 로그인, 프레임워크, npm 설치 (index.html 하나만 사용). 외부 연동은 구글 시트 제출 한 가지만 예외로 둔다.
- 교사가 화면에서 질문을 입력·수정하는 편집 모드
- 수업 중 실시간 답 공유 화면, 펜 필기의 자동 전송 (구글 시트에는 키보드로 쓴 답만 간다)
- 자동 채점, 정답 공개 기능
- 단어 뜻 팝업, 번역, 음성 읽기(TTS)
- 필기 인식(손글씨 → 텍스트), 도형·텍스트 상자 등 고급 필기 도구
- 다른 지문으로 바꾸는 기능, 여러 차시 관리
