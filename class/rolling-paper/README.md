# 롤링페이퍼

링크 하나로 여러 사람이 예쁜 메모지를 벽(게시판)에 붙이는 앱이에요.

- 주소: https://ereverse01.github.io/class/rolling-paper/
- 판 만들기 → 링크 공유 → 받은 사람은 메모지 색·글씨체·글씨 색·테이프/압정·스티커를 골라 메모를 붙여요.
- 배경 6종(코르크·칠판·핑크·밤하늘·모눈·민트), 메모지 12종, 손글씨 글꼴 6종.
- 다른 사람이 붙인 메모는 12초마다 자동으로 나타나요.
- 🖼️ 이미지로 저장: 게시판 전체를 PNG로 내려받아요.
- 지우기: 메모를 쓴 사람은 같은 기기에서 자기 메모를, 판을 만든 사람은 모든 메모를 지울 수 있어요.
  다른 기기에서 관리하려면 공유 창의 🔑 관리용 링크로 여세요.

## 구글 시트 연결 (여러 사람이 같이 쓰려면 꼭 필요)
`SHEET_URL` 이 비어 있으면 이 기기에만 저장되는 연습 모드예요.

1. 새 구글 시트 → 확장 프로그램 → Apps Script 에 `apps-script.gs` 붙여넣고 저장
2. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자) → 권한 허용
3. 웹 앱 주소(…/exec)를 `index.html` 의 `SHEET_URL` 에 넣기
4. 코드를 고치면 배포 관리 → 수정 → 새 버전 (주소는 그대로)

시트에 `판`, `메모` 탭이 자동으로 생겨요.
